TOPIC GROUP 01 · GRAPHS OF QUADRATICS

Parabolas and Intercepts

Exam task

Given a quadratic in any form, you must be able to sketch its parabola, find both intercepts, and explain what each intercept means. The x-intercepts are the solutions of the equation; the y-intercept is the value of the function at x = 0.

The shape of a parabola

Every quadratic function y = ax² + bx + c (with a ≠ 0) graphs as a parabola. The coefficient a controls the width and the direction of opening, while c is the y-intercept.

  • a > 0: the parabola opens upward and has a minimum point.
  • a < 0: the parabola opens downward and has a maximum point.
  • Larger |a| makes the parabola narrower; smaller |a| makes it wider. All parabolas are symmetric about a vertical line through the vertex.
y = x² − 6x + 8: two x-intercepts, one y-intercept and a vertex

The graph crosses the x-axis where y = 0 and crosses the y-axis where x = 0. The vertex sits on the axis of symmetry, midway between the two roots.

Finding the intercepts

FeatureHow to find itExample: y = x² − 6x + 8
x-interceptsSet y = 0, factorise or use the formula(x − 2)(x − 4) = 0 → x = 2, x = 4
y-interceptSet x = 0 and evaluatey = 8 → (0, 8)
Axis of symmetryx = −b/(2a), or midpoint of the rootsx = 3
VertexSubstitute the axis value into the equationy(3) = −1 → (3, −1)

x-intercept

A point where the graph meets the x-axis, so y = 0. These are the solutions (roots) of the quadratic equation. A parabola can have 0, 1 or 2 x-intercepts.

y-intercept

A point where the graph meets the y-axis, so x = 0. Every quadratic has exactly one y-intercept, and it is simply the constant term c.

Worked example — full sketch analysis of y = −x² + 4x + 5

y-intercept: at x = 0, y = 5, so (0, 5).

x-intercepts: solve −x² + 4x + 5 = 0. Multiply by −1: x² − 4x − 5 = 0 → (x − 5)(x + 1) = 0, so x = 5 and x = −1.

Axis of symmetry: x = −b/(2a) = −4/(2 × −1) = 2. As a check, the midpoint of 5 and −1 is also 2.

Vertex: y(2) = −4 + 8 + 5 = 9, so (2, 9). Since a = −1 < 0, this is the maximum.

Sketch: a downward parabola through (−1, 0), (0, 5), (2, 9) and (5, 0), symmetric about x = 2.

Factorise to (x − 2)(x − 3) = 0, giving x = 2 and x = 3. The numbers must multiply to +6 and add to +5, so both signs are negative inside the brackets — which reverses when each bracket is solved.
Interactive set · Self-check 2

The y-intercept of y = 2x² − 7x + 3 is:

A. (0, 3)
B. (3, 0)
C. (0, −7)
D. (0, 2)
Set x = 0; the first two terms vanish and y = 3. The constant term c always gives the y-intercept. Option B swaps the coordinates, which is the most common trap.
Interactive set · Self-check 3

A parabola has equation y = −(x − 1)(x + 5). Its x-intercepts are:

A. x = 1 and x = 5
B. x = 1 and x = −5
C. x = −1 and x = 5
D. x = −1 and x = −5
Each bracket set to zero gives x − 1 = 0 (x = 1) and x + 5 = 0 (x = −5). The factor (x + 5) corresponds to the intercept −5, not +5.

Do not confuse

Root, intercept and solution. The root is the number x; the x-intercept is the point (x, 0); the solution is the value that satisfies the equation. "Find the roots" asks for numbers like 2 and 4, while "state the x-intercepts" asks for coordinates (2, 0) and (4, 0).

TOPIC GROUP 02 · SYMMETRY AND TURNING POINTS

Axis of Symmetry and Vertex

Exam task

You must be able to find the axis of symmetry, the vertex, and decide whether it gives a maximum or minimum. Three routes are examinable: the formula x = −b/(2a), completing the square, and the midpoint of the roots.

The axis of symmetry

Every parabola is symmetric about the vertical line through its vertex. For y = ax² + bx + c, that line is:

x = −b / (2a)

The vertex lies on this line, so its x-coordinate is the same value. Subtracting the sign of b is the single most common error in this unit.

The axis of symmetry passes through the vertex and bisects the parabola

The dashed line is the axis of symmetry. Points on the parabola at equal horizontal distances from this line have the same height.

Three routes to the vertex

Formula

Compute x = −b/(2a), then substitute that x into the equation to get y. Fastest for standard form, and always works.

Completing the square

Rewrite as y = a(x − h)² + k. The vertex is (h, k) directly. Best when the question asks for vertex form or exact surds.

  • Midpoint of the roots: if the x-intercepts are p and q, the axis is x = (p + q)/2. This is often the quickest route when the roots are already known.
  • Sign of a: a > 0 gives a minimum at the vertex; a < 0 gives a maximum. The y-coordinate of the vertex is that extreme value.
EquationAxisVertexExtreme value
y = x² − 6x + 8x = 3(3, −1)Minimum −1
y = −x² + 4x + 5x = 2(2, 9)Maximum 9
y = 2x² + 8x + 6x = −2(−2, −2)Minimum −2
y = (x + 4)² − 7x = −4(−4, −7)Minimum −7
Worked example — vertex of y = 2x² + 8x + 6, and a sign-error critique

Axis: x = −b/(2a) = −8/(2 × 2) = −2.

Vertex: y(−2) = 2(4) + 8(−2) + 6 = 8 − 16 + 6 = −2, so (−2, −2).

Maximum or minimum: a = 2 > 0, so the parabola opens upward and the vertex is a minimum.

Common error: a student writes x = +2, using +b/(2a). That places the vertex on the wrong side of the y-axis. Notice that the y-coordinate can still come out correct by coincidence, which is why the x-coordinate must be checked separately.

Check by completing the square: y = 2(x² + 4x) + 6 = 2[(x + 2)² − 4] + 6 = 2(x + 2)² − 2, confirming (−2, −2).

The squared term is at least zero, and a = −3 makes the whole term non-positive, so the largest value is 12, reached at x = 2. The value 2 is the x-coordinate, not the maximum.

Do not confuse

Axis value vs vertex. "Find the axis of symmetry" answers with a line, x = 2. "Find the vertex" answers with a point, (2, 9). Writing the vertex as a single number, or the axis as a point, loses the communication mark even when the arithmetic is right.

TOPIC GROUP 03 · EQUIVALENT FORMS

Forms of a Quadratic

Exam task

The same parabola can be written in three forms. Each form reveals different information instantly. You must be able to convert between them and choose the most efficient form for the question.

FormEquationReveals immediatelyBest for
Standardy = ax² + bx + cy-intercept (0, c); direction from aFinding the y-intercept, using the formula
Factoredy = a(x − p)(x − q)x-intercepts p and qFinding roots and the axis midpoint
Vertexy = a(x − h)² + kVertex (h, k) and extreme valueMaximum/minimum problems and transformations

Command terms

Express or write in vertex form means complete the square and show the intermediate line. Hence means use the result you just found. Show that requires every algebraic step, not just the final equation.

Converting between forms

  • Factored → standard: expand the brackets and collect like terms.
  • Standard → factored: factorise, often by inspection or the ac method.
  • Standard → vertex: complete the square, or use x = −b/(2a) and substitute.
  • Vertex → standard: expand a(x − h)² + k.
  • Any form → a specific parabola: substitute a known point to find a.
Worked example 1 — from intercepts and a point to an equation

Task: A parabola has x-intercepts at x = 2 and x = −4 and passes through (0, −8). Find its equation.

Step 1 — start factored: y = a(x − 2)(x + 4).

Step 2 — substitute the point: −8 = a(0 − 2)(0 + 4) = −8a, so a = 1.

Step 3 — expand: y = (x − 2)(x + 4) = x² + 2x − 8.

Check: x = 0 gives −8; x = 2 and x = −4 both give 0. All three conditions are satisfied.

Worked example 2 — from vertex and a point to an equation

Task: A parabola has vertex (3, −2) and passes through (1, 6). Find its equation in vertex form.

Step 1 — start vertex form: y = a(x − 3)² − 2.

Step 2 — substitute the point: 6 = a(1 − 3)² − 2 = 4a − 2.

Step 3 — solve: 4a = 8, so a = 2.

Answer: y = 2(x − 3)² − 2. Check: x = 1 gives 2(4) − 2 = 6.

Which equation is written in vertex form?

Vertex form is y = a(x − h)² + k. Only C has a squared bracket plus a constant outside it, revealing the vertex (−2, 5). A is standard, B is factored, D is linear.
Interactive set · Self-check 2

The factored form y = 3(x − 1)(x + 5) has x-intercepts:

A. x = 1 and x = −5
B. x = −1 and x = 5
C. x = 1 and x = 5

Set each bracket to zero: x − 1 = 0 gives 1, and x + 5 = 0 gives −5. The constant multiplier 3 stretches the graph but does not move the intercepts.
Interactive set · Self-check 3

Expanding y = 2(x − 3)² − 8 gives:

A. y = 2x² − 6x + 10
B. y = 2x² + 12x + 10
C. y = 2x² − 12x − 8
D. y = 2x² − 12x + 10
(x − 3)² = x² − 6x + 9. Doubling gives 2x² − 12x + 18, then subtracting 8 gives 2x² − 12x + 10. Forgetting to double every term inside is the usual error.

Do not confuse

The value of a. The leading coefficient a is the same in all three forms. Expanding or factorising changes how the expression is written, not the shape of the parabola. If a changes, you are looking at a different parabola.

TOPIC GROUP 04 · APPLYING QUADRATICS

Quadratic Models

Exam task

Real contexts are marked on three things: the equation you form, the mathematical answer you obtain, and the interpretation of that answer in context. Always define variables, give units, and reject values that are physically impossible.

The modelling cycle

  1. Define the variables and their units (time in seconds, height in metres).
  2. Form the quadratic from the information given.
  3. Solve using the most efficient method: vertex, roots or discriminant.
  4. Interpret the result in the original context, including the domain.
  5. Evaluate the model: state an assumption and its likely effect.
What the question asksWhich part of the parabolaTypical method
Maximum height or revenueVertexx = −b/(2a), then substitute
When it hits the groundPositive x-interceptSet y = 0 and solve
Starting valuey-interceptSet x = 0
Is a target possible?DiscriminantCompare the target with the maximum

Projectile models

A common model is h = −5t² + ut + h₀, where u is the initial upward velocity and h₀ is the starting height. The coefficient −5 is an approximation of −g/2 with g ≈ 10 m/s².

Worked example — h = −5t² + 30t

Maximum height: the vertex occurs at t = −b/(2a) = −30/(−10) = 3 s. Then h(3) = −45 + 90 = 45 m.

Flight time: set h = 0: −5t² + 30t = 0 → −5t(t − 6) = 0, so t = 0 (launch) or t = 6 s (landing). The flight time is 6 s.

Symmetry check: the landing time 6 s is twice the time to the vertex, 3 s, as expected for a symmetric parabola launched from ground level.

Interpretation: the model predicts a maximum height of 45 m at 3 s and a total flight time of 6 s, ignoring air resistance.

Revenue and area models

  • Revenue: R = price × quantity. If price depends on quantity, the product becomes quadratic and the vertex gives maximum revenue.
  • Area with fixed perimeter: a rectangle with fixed fencing forms a quadratic in one side length; the vertex gives the maximum area.
  • Domain: lengths and quantities cannot be negative, so reject negative roots even when the algebra produces them.
Worked example — revenue R = 60x − 2x²

Maximum revenue: a = −2 < 0, so a maximum exists. x = −b/(2a) = −60/(−4) = 15 items.

Maximum value: R(15) = 900 − 450 = 450, so the maximum revenue is $450.

Interpretation: selling 15 items maximises revenue. Selling more items lowers the price enough that total revenue falls.

Evaluation: the model assumes a linear price–quantity relationship; real demand may not behave this way at very high or very low quantities.

Interactive set · Self-check 1

A ball's height is h = −5t² + 20t. It returns to the ground at:

A. t = 2 s
B. t = 4 s
C. t = 20 s
D. t = 5 s
Set h = 0: −5t(t − 4) = 0, so t = 0 or t = 4. The nonzero root is the landing time. The value t = 2 is when the ball reaches its maximum height, not when it lands.
Interactive set · Self-check 2

Revenue R = 40x − x² is maximised when x equals:

A. 40
B. 10
C. 20
D. 400
x = −b/(2a) = −40/(−2) = 20. The maximum revenue is then 800 − 400 = 400 dollars, but the question asks for the quantity, not the revenue.
Interactive set · Self-check 3

For a projectile, the vertex of the height–time graph represents:

A. The time and height of maximum height
B. The launch height only
C. The total flight time
D. The acceleration due to gravity
The vertex coordinates are (time, height), so both the moment of greatest height and the height itself are read from it. The launch height is the y-intercept; the flight time is where the graph returns to h = 0.

Do not confuse

Model answer vs real answer. A negative root usually represents a time before the motion started, and a negative length is impossible. State clearly that you reject it because of the context; simply crossing it out without a reason does not earn the interpretation mark.

TOPIC GROUP 05 · ROOTS AND THE DISCRIMINANT

Discriminant and Complex Roots

Exam task

The discriminant Δ = b² − 4ac tells you how many real roots a quadratic has before you solve it. A negative discriminant leads to complex roots, written as a ± bi.

DiscriminantReal rootsGraphTypical wording
Δ > 0Two distinct real rootsCrosses the x-axis twice"Show that the equation has two solutions"
Δ = 0One repeated real rootTouches the x-axis once"Find k for equal roots"
Δ < 0No real roots (two complex roots)Never meets the x-axis"Show that there are no real solutions"
The three discriminant cases

The discriminant is the part under the square root in the quadratic formula, so its sign decides whether that square root is real, zero or imaginary.

Complex roots

When the discriminant is negative, write the square root using i = √(−1). For example, √(−16) = 4i. The two roots then form a conjugate pair: if one root is a + bi, the other is a − bi.

Complex roots do not appear as x-intercepts. The parabola simply lies entirely above or entirely below the x-axis.

Worked example — solve x² + 2x + 5 = 0

Discriminant: b² − 4ac = 4 − 20 = −16.

Square root: √(−16) = 4i.

Quadratic formula: x = (−2 ± 4i)/2.

Simplify: divide every term by 2 to get x = −1 ± 2i.

Conjugate pair: −1 + 2i and −1 − 2i. The graph of y = x² + 2x + 5 does not cross the x-axis.

Worked example — equal roots condition

Task: Find k so that x² − 4x + k = 0 has equal roots.

Condition: equal roots require Δ = 0, so b² − 4ac = 0.

Substitute: 16 − 4k = 0, hence k = 4.

Check: x² − 4x + 4 = (x − 2)², which has the repeated root x = 2.

Interactive set · Self-check 1

The discriminant of x² − 6x + 9 is:

A. 72
B. 36
C. 0
D. −36
Δ = (−6)² − 4(1)(9) = 36 − 36 = 0. The quadratic is (x − 3)², so the parabola touches the x-axis once at x = 3.
Interactive set · Self-check 2

If b² − 4ac = −7, the equation has:

A. No real roots — a complex conjugate pair
B. One repeated real root
C. Two distinct real roots
D. Infinitely many roots
A negative discriminant means the square root is imaginary, so there are no real solutions. The two roots are complex conjugates, and the parabola does not meet the x-axis.
Interactive set · Self-check 3

The roots of x² − 2x + 5 = 0 are:

A. −1 ± 2i
B. 1 ± 2i
C. 1 ± 4i
D. 2 ± i
The discriminant is 4 − 20 = −16, so √(−16) = 4i. Then x = (2 ± 4i)/2 = 1 ± 2i. Remember to divide the whole numerator by 2.

Do not confuse

"No real roots" is not "no solutions". A negative discriminant means no real roots. The equation still has two complex roots, and the parabola still exists — it just never crosses the x-axis.

Quadratic checklist — the fastest way to score

For any quadratic: identify the form first (standard, factored or vertex), then choose the tool that reads the answer directly. For roots: factorise, complete the square, or use the formula. For the vertex: x = −b/(2a), then substitute. For a model: state the domain and interpret the answer in context. Check the sign of a before claiming a maximum or minimum.
